# 明确不用的 mygo 模块

> 状态：**已决策——不用。** 这份记录回答"全家桶里剩下的为什么不吃"。
> 判据不是"能不能做"，而是"做了是不是负收益"。

## 1. frontend（web 前端 + typed IPC）

**不用。** 三条理由，任何一条独立成立：

1. **约束消失方向相反**：本工具的界面是一个 10 列表格 + 撤销/重做都没有的只读计划页。
   web 前端带来的能力（富文档、复杂布局、现成组件库）没有一个被需要。
2. **成本是实的**：引入前端意味着 Bun + Vite 构建链、WebView2 运行时依赖、TypeScript
   客户端生成、以及"Go 与 JS 两套真相"的边界。当前 `internal/gui` 是纯 Go 单二进制，
   秒开、零 webview、内存 58MB。
3. **typed IPC 没有消费者**：GUI 与引擎在**同一进程**内直接函数调用。IPC 是跨进程边界的
   补偿手段，本仓库没有那个边界需要补偿。

**若将来翻案**：只有当出现"必须在浏览器里打开"的需求时（例如远程查看另一台机器的审计
结果），才重新评估；那时它是新入口，不是这个窗口的替换。

## 2. audio

**不用。** 无场景。驱动安装是分钟级后台任务，声音提示不是本工具要解决的问题；完成提示
已有日志面板、toast 与系统托盘。

## 3. plugins（web 插件体系）

**不用。** 它依赖 frontend 作为宿主：插件由"Go 服务 + JavaScript 包"两半组成，没有 web
页面就没有 JS 那一半的位置。frontend 不用的前提下，这个模块没有宿主。

## 4. launchers（Spotlight 式全局唤起）

**不用。** 平台等价物已经存在且更好：Windows 上是 PowerToys Run / `Win` 键搜索，macOS 是
Spotlight。再造一个全局快捷键唤起器，是用本工具的单薄实现去替代操作系统已经做好的索引与
排序。本工具需要的"快速打开"已经由**托盘图标**满足。

## 5. 附：被采用但受限的模块

| 模块 | 采用程度 | 限制 |
| --- | --- | --- |
| `menus` | 托盘菜单 + 表格行右键菜单 | 不做应用菜单栏（无 mac 目标） |
| `data-transfer` | 剪贴板只写纯文本 | 不做拖放、不做富格式 |
| `ui/editor` | 计划页只读视图 | 不做编辑、不做语法高亮 |
| `i18n` | 单语言 zh-Hans | 引擎日志保持英文（账本/计划的机器可读性） |
| `updates` | 显式点击检查 | 无后台轮询 |
| `distribution` | `mygo build` 产 exe + NSIS 安装器 | 无 Authenticode 证书，见 `distribution-unfrozen.md` |
