## 决策记录

- **D0（前置问题，一比一对比后）**：Vantage / Windows Update 与本工具的能力差异确实存在——本工具独有的**零遥测、确定性 WORM 审计账本、事实分级 fact/inference/undetermined、默认不动、知情授权回退**，三者都做不到。但这些差异是**自审型**能力：只有"对自己机器负责、想知道装了什么/何时/从哪来/前后版本"的单操作者才需要；一个只想"驱动正常 + 装坏了有人负责"的陌生用户，要的是签名/支持矩阵/厂商责任（Vantage/WU 有，本工具无）。
- **结论**：不分发。理由不是"无差异"，而是**差异的受众是自审者，自审者不需要分发成品**。当前状态即终态。

## 0. 比 D1–D5 更前置的问题：分发要解决什么

先别问"如何分发"，先问"分发解决哪个**尚未被解决**的问题"。Windows Update 与 Lenovo Vantage
已经提供带签名、带支持矩阵、带官方责任的驱动安装与回退；本工具对陌生用户的增量价值是
"确定性审计 + 事实分级 + 知情授权 + 零遥测"。而这些价值恰恰只有**单操作者、自己对自己负责**
时才成立——分发给他人时，确定性被多机/多用户稀释，事实分级需要每机型重建证据，零遥测与
"问题反馈/责任追溯"直接冲突。

**反方判断（待证伪）**：分发很可能是一个类别错误——这个工具的天然天花板是"极致的个人审计
工具"，不是"又一个驱动安装器"。把"分发"当成长远目标，等同于去和 Windows Update / Vantage
在同一条赛道竞争，还自动放弃了自己唯一的护城河（单机确定性审计）。因此默认结论不是"怎么
分发"，而是"不分发，且这是优点，不是缺陷"。

若你认为上面有误，请先回答：分发后，它做**哪一件** Windows Update / Lenovo Vantage 做不到、
而你的目标用户又真正需要的事？答不出这一件，D1–D5 都不必填。

## 1. 当前硬约束（不可回退）

`AGENTS.md` 已定：**部署形态 = 个人单机审计脚本**。产品尾（自签名、支持矩阵、安装器/卸载器、
升级、遥测、品牌合规）**冻结**。以下性质是审计脚本规格的不可回退约束：

1. 确定性：零遥测、无隐藏联网、无后台服务。
2. 证据优先。
3. 默认不动。
4. 事实分级 fact/inference/undetermined。
5. 审计先于状态变更。
6. 设备级回退（回退驱动程序或重装旧 INF），`/delete-driver` 只做包清理。

**结论**：这些约束是"单操作者、单机、自己对自己负责"的语义。分发给他人会系统性冲突。

## 2. "分发"到底需要什么（比回滚/CSV 更前置的门）

| 门 | 现状 | 分发需要 |
| --- | --- | --- |
| 签名/信任 | 自签名（冻结） | Authenticode 证书（否则 SmartScreen/AV 报毒） |
| 支持矩阵 | 单机 82JQ（事实标准以它验证） | 多机型实测 + 每机型事实分级证据 |
| 审计模型 | 单操作者，自己审计自己 | 多用户、他触发、责任可追溯 |
| 责任边界 | 无（自己装坏自己负责） | 装坏别人机器的责任、免责/支持承诺 |
| 更新/遥测 | 冻结（零遥测） | 升级通道、问题反馈（与零遥测冲突） |
| 卸载/安装器 | 冻结 | 分发形态需要的交付物 |

**关键判断**：签名 + 支持矩阵 + 责任边界是分发的**第一道门**。回滚、CSV 列序是"顺手该做的
正确性卫生"，不是分发的前置——做完它们，分发的门一步没动。

## 3. 决策维度与选项

### D1 分发给谁
- A. 不分发，维持单机审计脚本（零改动）。
- B. 发给少数可信的人（家人/同事，个位数），口头责任边界。
- C. 公开分发（网上放出，未知用户）。

### D2 支持矩阵
- A. 只支持 82JQ 一台。
- B. 支持一类（如 Lenovo Legion 2021 系列，需逐台实测）。
- C. 全量 Lenovo 机型（需要官方品类/机型矩阵 + 大量实测，工作量巨大）。

### D3 签名
- A. 继续自签名，用户手动信任（SmartScreen 会拦，不适合 C 分发）。
- B. 购买 OV/EV 代码签名证书（有年费与实名/组织要求），解决 SmartScreen。
- C. 不签，走"源码给用户自己 build"（损失可用性，保留确定性）。

### D4 审计/责任模型
- A. 维持"触发人 = 审计人 = 唯一操作者"。
- B. 多用户：引入"谁触发、在哪台机、哪次会话"的身份与流水号（扩大审计对象，是领域模型大改）。

### D5 产品尾解冻范围
- 逐项决定：升级/遥测/卸载器/安装器是否解冻、解冻到何种程度，且**不得违反**第 1 节六条不变量。
